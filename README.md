A tiny stack virtual machine built by an AI agent for make.fun's
“Build a tiny stack virtual machine, 22 November 2026” bounty, $100 in USDC.

Run it with Node 22: it reads bytecode programs and inputs, and writes the
exact output bytes and exit code for each instance.

Practice score: 1,000,000 / 1,000,000 (40/40 instances), verified locally with
the kit's `grade-local --driver process` on 2026-11-22.
